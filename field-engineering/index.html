What We Handle

Field Engineering Scope

  • FECN Issuance

    Field engineering change notices issued, tracked, and closed out on site. Approved through the correct authorization chain — not verbal workarounds that create liability.

    • FECN drafted on site with field-verified dimensions and conflict description
    • Authorization matrix followed: contractor PM, owner rep, and RTS field engineer sign-off tiers
    • FECN logged with impacted drawings, reason for change, and full approval chain documentation
    • Redlines issued to installation crew same day — no delays waiting on office review
    • Final FECN package rolled into as-built documentation at project close

  • RFI Technical Response

    Technical RFI responses with field-verified dimensions, equipment confirmations, and engineering rationale — not generic hold-harmless language.

    • Field measurements and clearances verified before response is issued
    • Vendor documentation reviewed on site: equipment submittals, IOM, and dimensional drawings
    • Response includes engineering rationale and impacted drawing references with markup
    • RFI log updated; outstanding RFIs reported to project manager daily
    • Technically defensible responses — authored with field verification behind every decision

  • Fit Issue Resolution

    Conduit routing conflicts, instrument mounting clearance problems, support interference — identified in the field, resolved with documented solutions before rework compounds.

    • Conduit routing conflicts identified and alternative route documented with field sketch
    • Instrument mounting and access clearance issues resolved with written FCN same day
    • Support and structural interference documented with photos and field sketches
    • Resolution issued before crew moves to next task — no verbal workarounds
    • Rework prevention log maintained for lessons-learned and project closeout

  • As-Built Documentation

    As-built markups captured as work progresses — not reconstructed from photos at project end. Final package formatted for client document control submission.

    • Redlines captured on P&IDs, loop drawings, and electrical drawings daily as work progresses
    • Field-verified changes documented: routing deviations, tag relocations, cable substitutions
    • Drawing set maintained current throughout project — not assembled from memory at closeout
    • Final as-built package formatted per client document control requirements
    • Digital delivery in Bluebeam and PDF; hard copy available on request

  • Vendor Witness Testing

    Third-party witness testing at vendor facilities for instruments, panels, and packaged equipment. FAT documentation, punchlist, and acceptance sign-off included.

    • Witness testing planned with vendor scheduler and executed to approved ATP/FAT procedure
    • FAT documentation review: I/O checkout, functional test, calibration cert, and nameplate data
    • Punchlist items noted at vendor facility and tracked through to closure before shipment
    • Hold points verified and confirmed before final acceptance sign-off is issued
    • Witness report and acceptance documentation provided within 48 hours of test completion
