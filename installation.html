What We Install

Rogue Technical Services performs full electrical and instrumentation installation for new construction, plant expansions, and capital projects. We operate as a standalone E&I installation contractor — bringing the field experience, technical discipline, and documentation standards that industrial projects demand.

Correct installations. Tight terminations. Complete documentation. No surprises when the next phase starts.

Electrical Installation

  • Conduit systems — rigid, EMT, HDPE, and fiberglass
  • Cable tray, ladder rack, and wireway installation
  • Power and control cable pulling
  • Cable termination and lug installation
  • Motor and equipment connections
  • Lighting, receptacles, and panel feeders
  • Grounding and bonding systems
  • Electrical equipment installation and setting

Instrumentation Installation

  • Transmitter, switch, and analyzer installation
  • Flow meter and primary element setting
  • Control valve and actuator mounting
  • Junction box and marshalling enclosure installation
  • Instrument tubing and impulse piping
  • Field instrument cable pulling and termination
  • Instrument support and bracket fabrication
  • DCS/PLC I/O termination and field wiring

Hazardous Area & NEC Work

  • Class I Division 1 & 2 electrical installation
  • Explosion-proof conduit sealing and fittings
  • Intrinsically safe wiring system installation
  • Purged and pressurized enclosure installation
  • Area classification verification against drawings
  • Ex-rated instrument and device installation
  • NEC Article 501/502 compliance verification

Panels, MCC & Switchgear

  • MCC and motor control center setting and termination
  • Switchgear and distribution panel installation
  • Control panel wiring and internal termination
  • PLC/DCS cabinet installation and power-up
  • UPS and battery backup systems
  • Instrumentation panel internal wiring
  • Pre-energization inspection and point-to-point verification

Documentation & As-Builts

Every installation Rogue performs is documented to turnover standards from day one. We don't retrofit paperwork at the end of the job — we build the documentation package alongside the installation so it's complete, accurate, and ready when the next phase of your project begins.

Installation Records

  • Completed installation inspection checklists per tag/circuit
  • Material traceability records and equipment serial numbers
  • Cable schedule updates — routing, termination, test results
  • Torque records for electrical terminations and bolted connections
  • Conduit seal installation records (hazardous area)
  • Grounding resistance test records

As-Built Drawings & Turnover

  • Red-line as-built markup on electrical and instrumentation drawings
  • Updated cable schedules reflecting final routing and cuts
  • Instrument index updates for installed devices
  • Pre-commissioning readiness certificates per discipline
  • Photo documentation of installation milestones
  • Punch list package for commissioning handoff

What Sets Our Installation Apart

E&I installation is a craft. The difference between a clean install and a problem install shows up in the details — a termination that's one lug short, a conduit seal that wasn't filled, a ground that was jumped over. Rogue brings the field experience and discipline to get those details right every time, on every project.

Built to Spec — Every Time

We install against the drawings, data sheets, and applicable codes — NEC, ISA, client specs. We don't improvise. If something conflicts with the design, we flag it before we build it wrong.

Hazardous Area Experience

Class I Division 1 and 2 work requires getting it right — conduit seals, fitting selection, certified equipment. We've done it in natural gas, compression, and refining environments where the stakes are real.

Documentation Built Alongside the Work

Installation records, cable schedules, as-built markups, and inspection checklists are completed as the job progresses — not assembled at the end from memory. The package is ready when you need it.

Field-Experienced Crew

Our people have worked industrial E&I across natural gas, compression, LNG, and refinery environments. They know the equipment, the failure modes, and how to install correctly the first time.

Need commissioning or reliability services on the same project? Rogue offers those as separate services — ask us about full-scope options when you reach out.
